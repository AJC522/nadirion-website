Nadirion Desktop: one application, every module

Nadirion Desktop is the platform every license starts with. A single launcher hosts the modules you choose, a keyboard-driven console runs them by name, and settings, in-app guidance, and verified updates tie it together. It was previously released as the Threat Operations Toolset.

01 Included

What every license includes

These come with Nadirion Desktop itself, whichever add-on modules you choose. They are the parts every module leans on.

D-01

Unified launcher

Every module you own in one window, grouped by workflow stage. Reorder the categories to match how your team works.

D-02

Search by what you're hunting

The filter box matches names, descriptions, and the words analysts actually type: “autoruns”, “netstat”, “evtx”. Enter opens the first match.

D-03

Command Console

Run modules by name, headless or windowed, beside safe shell-style utilities and an offline MITRE ATT&CK lookup.

D-04

Knowledge Base

Press F1 for guidance on every module: what it reads, what it flags, and what to corroborate before you act on it.

D-05

Settings & keys

Themes, bundled typefaces, a color-vision mode, display scaling, and API keys stored in the operating system's keyring.

D-06

Module health & updates

Per-module dependency checks with clear fixes (F5 re-checks), and in-place updates verified by SHA-256 before they are swapped in.

02 Command Console

Every module, by name

The console runs inside the desktop or as its own shell. Each module you license gets a first-class command, and most run headless right there in the console.

nadirion desktop · command console 
nadirion> attack T1566
  › Phishing · Initial Access ............ offline catalog
nadirion> eventlogon --security Security.evtx --flagged
  › logon sessions scored ................... 3 bursts flagged
nadirion> securehost --status
  › network isolation ....................... off
nadirion> triagekit --verify --kit E:\
  › manifest re-hashed ...................... unchanged
nadirion>

Two ways to run the same thing

A module's window and its console command share one engine, so results reproduce either way.

Safe by default

Shell-style commands are emulations that never spawn a real shell. Anything that changes a host needs --yes, and real shell passthrough stays off until you turn it on.

Goes where the host is

With Triage Kit USB, the console and the command-line modules travel on a USB drive to a machine with nothing installed.

03 Add-on Modules

How the modules fit in

Modules are sold one at a time, but they are built to sit together in the same launcher and hand work to one another.

Same window, same console

An add-on opens from the launcher under its category and runs by name from the console, with the same shortcuts as everything else.

Modules that hand off

Indicators from Intelligence Processor, File Analysis, Process Analysis, and Email Analysis can go straight into IOC Vault.

Add any time

Start with the one module your work needs today. Add more to the same license when the work changes.

04 Install

Runs where your analysts work

A native package for each desktop platform, with no Python or other runtime to install first. Once installed, Nadirion Desktop updates itself in place.

Nadirion Desktop packages by platform
PlatformPackageInstalls asUpdates
WindowsSetup wizard (.exe), x86_64Per-user install with no admin rights needed; Desktop and Start Menu shortcutsIn place, SHA-256 verified
macOSDisk image (.dmg), x86_64Drag to ApplicationsIn place, SHA-256 verified
LinuxArchive (.tar.gz), x86_64Install script places it in ~/.local/bin with an application-menu launcherIn place, SHA-256 verified

Nothing else to install

Each package is self-contained. Optional extras, such as ffmpeg for audio and video conversion, are detected when present.

Admin only when needed

Day-to-day use runs as a normal user. Modules that write whole drives, such as USB ISO Burner, ask for administrator rights.

Your data stays local

Settings, cases, and caches live in a per-user folder on the workstation. API keys live in the OS keyring.

Platform notes

A few modules read Windows-specific artifacts or behave differently per platform. Each module's catalog entry says where.
