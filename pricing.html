04 Questions

Licensing FAQ

The questions buyers ask most. If yours isn't here, ask us.

Do I need Nadirion Desktop to use a module?

Yes. Modules are add-ons: they run inside Nadirion Desktop, open from its launcher, and run by name from its console. Every license includes the desktop.

Can I buy just one module?

Yes. The smallest license is Nadirion Desktop plus a single add-on module.

Can I add modules later?

Yes. Add-ons join an existing license whenever you need them, so you can start small and grow it as your work changes.

Which platforms are supported?

Windows, macOS, and Linux on x86_64. A few modules read Windows-specific artifacts, such as registry hives and event logs, or behave differently per platform; each module's entry in the catalog says where.

Do the modules need an internet connection?

Most work fully offline. Modules that enrich indicators or run web lookups use your own API keys for services such as VirusTotal, AbuseIPDB, Hybrid Analysis, and SerpAPI. Those services are licensed separately by their providers.

Can I buy through a reseller?

Yes. Certified resellers sell Nadirion Desktop and every add-on. Ask for the reseller's ID and confirm it with us before you pay.

What happened to the Threat Operations Toolset?

It is now Nadirion Desktop. The modules are the same tools, now sold as add-ons to the desktop. If you run an earlier release, get in touch about moving to a Nadirion license.

What about modules that are still in development?

Intelligence Map and Investigation Queue are in development and not yet sold. Ask and we'll tell you when they ship.
