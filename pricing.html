05 Questions

Licensing FAQ

The questions buyers ask most. If yours isn't here, ask us.

Do I need Nadirion Desktop to use a module?

Yes. Modules run inside Nadirion Desktop, open from its launcher, and run by name from its console. Nadirion Desktop is $150 per user per year and includes the four Triage modules and the eight Host Utilities.

Can I buy just one module?

Yes. The smallest license is Nadirion Desktop on its own, which already includes 12 modules. Add any other module for $50 per user per year, or $100 for a Premium module.

Can I add modules later?

Yes. Modules can be added to an existing subscription at any time.

Which platforms are supported?

Windows, macOS, and Linux on x86_64. Several forensic modules read Windows-only artifacts, such as registry hives, Prefetch, and event logs, and a few modules are best-effort on macOS. Each module's entry in the catalog states its limits.

Do the modules need an internet connection?

Most work fully offline. Modules that enrich indicators or run web lookups use your own API keys for services such as VirusTotal, AbuseIPDB, Hybrid Analysis, and SerpAPI. Those services are licensed separately by their providers.

What does “Preview” mean?

Preview marks a module that is on sale but newer, or with less real-world testing behind it, than the rest; expect rougher edges. Preview modules are 30% off for our first 25 customers. No module is in Preview right now. Preview is different from “in development”: modules in development are not sold at all.

Is there a perpetual license?

Yes. There is no set rate; the price of a perpetual license is negotiated for each purchase. Request a quote with the modules and number of users you need.

Can I buy through a reseller?

Yes. Certified resellers sell Nadirion Desktop and every add-on. Ask for the reseller's ID and confirm it with us before you pay.

What happened to the Threat Operations Toolset?

It has been renamed Nadirion Desktop. Its modules are the same tools, now sold as add-ons to the desktop. If you use an earlier release, contact us about moving to a Nadirion license.

What about modules that are still in development?

Intelligence Map and Investigation Queue are in development and not yet available for purchase. Both will be Premium modules ($100 per user per year) when released. Ask, and we'll let you know when they ship.
