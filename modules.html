Intelligence

Collect, enrich, store, and follow threat intelligence, from a pasted advisory to a team-shared indicator repository.

Intelligence Processor

Extract, normalize, and enrich indicators from raw text, files, and URLs.

  • Parallel enrichment across VirusTotal, AbuseIPDB, and Hybrid Analysis
  • Exports the normalized set as JSON, CSV, or STIX 2.1
  • GUI + console
  • Uses your API keys
INT-02

IOC Vault

An encrypted repository for indicators and threat-actor records that a whole team can share.

  • AES-256-GCM encryption at rest
  • CSV, Excel, STIX, and MISP import and export, plus a SentinelOne IOC Management export
  • Team sync over a network share with concurrent-writer protection
  • GUI + console
  • Encrypted
INT-03

Intelligence Feed

Curated security news, government advisories, and CVE tracking in one feed.

  • Polls RSS, Atom, and JSON feeds across cyber, advisory, and vulnerability sources
  • Tags severity, extracts CVE identifiers, and flags your watchlist hits
  • Search, priority filters, and export to TXT, CSV, JSON, or HTML
  • GUI + console

Forensics

Read-only host and artifact analysis with transparent scoring: files, email, processes, browsers, persistence, execution history, and event logs.

11 modules
FOR-01

File Analysis

Static triage of a suspicious file before anyone opens it.

  • Hashes, entropy, and MIME and extension mismatch checks
  • Filename anomalies and embedded string signals
  • Separates likely-benign files from the ones that need escalation
  • GUI + console
  • Read-only
FOR-02

Email Analysis

Phishing analysis of .eml and .msg messages that never renders, fetches, or opens anything.

  • SPF, DKIM, and DMARC alignment, Received chain, lookalike-domain and BEC Reply-To checks
  • Explainable rules with a severity and MITRE ATT&CK technique on every finding
  • A decision-first verdict, from Benign through Likely Phishing to Malicious
  • GUI + console
  • Opt-in enrichment
FOR-03

Process Analysis

Score running processes, with the rule-level reasoning behind every score.

  • Hashes and signature status for every process binary
  • Each process's listening and established network connections
  • Baseline comparison and exportable reports for handoff
  • GUI + console
  • Windows-first
FOR-04

Browser Analysis

History, downloads, and search-term triage across Chromium and Firefox browsers.

  • Edge, Chrome, Brave, Vivaldi, Opera, Firefox, Waterfox, and LibreWolf
  • Flags URL shorteners, paste sites, tunneling and remote-access services, and risky downloads
  • Full Scan covers every profile on the host, including Volume Shadow Copy history
  • GUI + console
  • Full Scan: Windows
FOR-05

Service Analysis

Inventory installed services and flag the ones that don't belong.

  • Status, start type, and binary path for every service
  • Flags unsigned binaries, user-writable or unusual paths, and missing descriptions
  • Windows services, Linux systemd units, and macOS launchd
  • GUI + console
  • Read-only
FOR-06

Scheduled Task Analysis

Find persistence hiding in scheduled tasks, cron jobs, and systemd timers.

  • Task Scheduler on Windows, cron and systemd timers on Linux, cron on macOS
  • Flags very frequent triggers and unsigned, user-writable, or LOLBin action binaries
  • Surfaces disabled-but-present entries
  • GUI + console
  • Read-only
FOR-07

Registry & Persistence Analysis

Parse offline or live registry hives for persistence and user activity.

  • Run keys, AppInit_DLLs, Winlogon, IFEO, LSA packages, and COM hijack candidates
  • UserAssist, RecentDocs, and ShellBags activity
  • Works on exported hives or auto-detects them on the host
  • GUI + console
  • Windows artifacts
FOR-08

Execution Evidence Analysis

One “what ran, and when” timeline from Prefetch, Amcache, and BAM/DAM.

  • Point it at exported artifacts or let it find them on the host
  • Merges every source into a single scored timeline
  • Read-only, with scans on a background thread
  • GUI + console
  • Windows artifacts
FOR-09

Event Log & Logon Analysis

Turn Security, Sysmon, and PowerShell event logs into a logon and execution story.

  • Logon-session report with brute-force burst detection
  • Scores process-creation and PowerShell script-block evidence
  • Cross-references findings exported from other analysis modules
  • GUI + console
  • Windows logs
FOR-10

AI Analysis

Score photos, video, text, and code for generative-AI creation or editing, and show the evidence.

  • Provenance, artifact, and heuristic evidence tiers; the strongest tier present caps the score
  • Style-only verdicts stop at 70/100; anything higher needs evidence that names a generator
  • Scores “created” and “edited” separately, so a retouched camera photo isn't called synthetic
  • GUI + console
  • Read-only
FOR-11

Network Connection Forensics

A point-in-time record of who this host is talking to.

  • Live inbound and outbound connections
  • Firewall and listening-port exposure audit
  • ARP table and the DNS resolver cache (Windows)
  • GUI + console
  • Read-only

Triage

Act on a host you suspect: sweep it, isolate it, carry a read-only kit to it, or build clean boot media for it.

4 modules
TRI-01

Malware Scan

One sweep that correlates persistence, execution, event-log, network, and file-hiding indicators.

  • Quick Scan in-app, or a Full Scan through the bundled PowerShell collector
  • Blocklist escalation and opt-in VirusTotal verdicts
  • Reversible remediation that confirms first and verifies the result
  • GUI + console
  • Full Scan: Windows
TRI-02

Secure Host

Isolate a compromised host from the network, with a full undo.

  • Blocks all traffic except loopback and an optional allowed address, such as your jump host
  • Snapshots the firewall configuration first, so Restore is exact
  • Snapshot-exact on Windows and Linux; best-effort on macOS
  • GUI + console
  • Reversible
TRI-03

Triage Kit USB

Build a read-only, no-install incident-response kit onto a USB drive.

  • Standalone Windows and Linux/macOS collectors, plus a portable console of the CLI modules
  • Nothing on the host is modified; results write back to the kit
  • SHA-256 manifest and Verify Kit for chain of custody
  • GUI + console
  • Read-only kit
TRI-04

USB ISO Burner

Turn a forensic live-boot ISO or an OS installer into verified bootable USB media.

  • Raw (DD) mode for hybrid ISOs; file-copy mode for Windows installers, Secure Boot included
  • Checks the expected checksum before writing and reads the drive back after
  • Only ever offers removable drives, re-identified at burn time
  • GUI + console
  • Admin rights

Cryptography

Decoder

An offline workbench for encoded, obfuscated, and hashed text.

  • GUI
  • Fully offline

  • GUI + console

Startup Manager

Inspect and enable or disable startup entries, reversibly.

  • Run keys, Startup folders, and auto-start services on Windows
  • XDG autostart and systemd on Linux; launchd on macOS

  • GUI + console
  • Reversible
HST-04

System Health Snapshot

A quick CPU, memory, disk, battery, and uptime snapshot.

  • Capture host state before and after triage

  • Diff a later run against the first
  • GUI + console
  • Read-only

Disk Space Analyzer
