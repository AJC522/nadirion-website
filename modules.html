Intelligence

Extract indicators from reports, look them up in services you hold keys for, keep them in a shared repository, and follow public advisories.

3 modules
INT-01

Intelligence Processor

Extracts indicators from raw text, files, and URLs, normalizes them, and looks them up in the services you hold API keys for.

  • Extracts IP addresses, domains, URLs, email addresses, hashes, CVEs, and filenames, and re-fangs defanged indicators
  • Runs VirusTotal, AbuseIPDB, and Hybrid Analysis lookups in parallel
  • Exports the normalized set as JSON, CSV, or STIX 2.1
  • GUI + console
  • Uses your API keys
INT-02

IOC Vault

A shared repository of indicators and threat-actor records, stored in a database file encrypted with AES-256-GCM.

  • AES-256-GCM encryption of the database at rest
  • CSV, Excel, STIX, and MISP import and export, plus a SentinelOne IOC Management export
  • Team sync through a network share, with protection against concurrent writes
  • GUI + console
  • AES-256-GCM at rest
INT-03

Intelligence Feed

Security news, government advisories, and CVE announcements from public feeds, gathered into one list.

  • Polls RSS, Atom, and JSON feeds across cyber, advisory, and vulnerability sources
  • Tags severity, extracts CVE identifiers, and flags items that match your watchlist
  • Search, priority filters, and export to TXT, CSV, JSON, or HTML
  • GUI + console

Forensics

Read-only review of files, email, processes, browsers, persistence, execution history, and event logs. Every score lists the rules behind it. Most of these modules are Windows-first.

11 modules
FOR-01

File Analysis

Static checks on a suspicious file before anyone opens it.

  • Hashes, entropy, and checks for a MIME type that doesn't match the file extension
  • Filename anomalies, embedded string signals, and VirusTotal and Hybrid Analysis lookups by hash (the file itself is never uploaded)
  • Suggests whether the file looks benign or needs escalation, with the checks behind that suggestion
  • GUI + console
  • Read-only
  • Uses your API keys
FOR-02

Email Analysis

Rule-based phishing review of .eml and .msg files. It never renders HTML, follows links, or opens attachments.

  • SPF, DKIM, and DMARC alignment; Received-chain analysis; and lookalike-domain and BEC Reply-To checks
  • Each finding names its rule, a severity, and a MITRE ATT&CK technique
  • An overall rating, from Benign through Likely Phishing to Malicious, shown with the findings that produced it
  • GUI + console
  • Opt-in enrichment
FOR-03

Process Analysis

Scores running processes and shows the rules behind each score.

  • Hash and signature status for each process binary
  • Each process's listening and established network connections
  • Baseline comparison and exportable reports for handoff
  • GUI + console
  • Windows-first
FOR-04

Browser Analysis

History, downloads, and search terms from Chromium- and Firefox-based browsers, with entries worth a closer look flagged.

  • Edge, Chrome, Brave, Vivaldi, and Firefox on every platform; Opera, Opera GX, Waterfox, and LibreWolf on Windows
  • Flags URL shorteners, paste sites, tunneling and remote-access services, and risky downloads
  • Full Scan reads every profile on the host, including history kept in Volume Shadow Copies
  • GUI + console
  • Full Scan: Windows
FOR-05

Service Analysis

Lists installed services and flags those with traits worth a closer look.

  • Status, start type, and binary path for every service
  • Flags unsigned binaries (Windows), user-writable or unusual paths, and missing descriptions
  • Windows services and Linux systemd units in full
  • GUI + console
  • Read-only
FOR-06

Scheduled Task Analysis

Lists scheduled tasks, cron jobs, and systemd timers, and flags entries that look like persistence.

  • Task Scheduler on Windows, cron and systemd timers on Linux, cron on macOS
  • Flags unusually frequent triggers and actions that run unsigned, user-writable, or LOLBin binaries
  • Lists entries that are disabled but still present
  • GUI + console
  • Read-only
FOR-07

Registry & Persistence Analysis

Parses live or exported Windows registry hives for persistence entries and user activity.

  • Run keys, AppInit_DLLs, Winlogon, IFEO, LSA packages, and COM hijack candidates
  • UserAssist, RecentDocs, and ShellBags activity
  • Works on exported hives or finds them on the host
  • GUI + console
  • Windows artifacts
FOR-08

Execution Evidence Analysis

A single what-ran-and-when timeline built from Prefetch, Amcache, and BAM/DAM.

  • Point it at exported artifacts or let it find them on the host
  • Merges every source into one scored timeline
  • Read-only, with scans running in the background
  • GUI + console
  • Windows artifacts
FOR-09

Event Log & Logon Analysis

Summarizes logon and execution activity from Security, Sysmon, and PowerShell event logs.

  • Logon-session report that flags bursts of failed logons, a common sign of password guessing
  • Scores process-creation and PowerShell script-block events
  • Cross-references findings exported from other modules
  • GUI + console
  • Windows logs
FOR-10

AI Analysis

Scores photos, video, text, and code for signs of generative-AI creation or editing, and shows the evidence behind each score.

  • Provenance (such as C2PA Content Credentials), artifact, and heuristic evidence tiers; the strongest tier present caps the score
  • Scores based on style alone stop at 70/100; a higher score needs evidence that names a generator
  • Scores “created” and “edited” separately, so a retouched camera photo isn't labeled synthetic
  • GUI + console
  • Read-only
  • Advisory scores
FOR-11

Network Connection Forensics

A point-in-time record of this host's connections, listening ports, and network neighbors.

  • Live inbound and outbound connections
  • Firewall rules and listening-port exposure
  • ARP table and the DNS resolver cache (Windows)
  • GUI + console
  • Read-only

Triage

Work on a suspect host: sweep it for indicators of compromise, cut it off from the network, collect from it with a USB kit, or write boot media for it. All four are included with Nadirion Desktop.

4 modules · included
TRI-01

Malware Scan

A heuristic sweep that correlates persistence, execution, event-log, network, and file-hiding indicators on a host. It is not antivirus: it has no signature database and no real-time protection.

  • Quick Scan in the app, or a Full Scan through the bundled PowerShell collector
  • Blocklist matching and optional VirusTotal lookups
  • Remediation asks for confirmation, quarantines or disables rather than deleting, and re-checks each item afterward
  • GUI + console
  • Windows-first
  • Not antivirus
✓ Included with Nadirion Desktop
TRI-02

Secure Host

Cuts a host off from the network with a block-by-default firewall policy, then restores the previous configuration when you're done.

  • Blocks inbound and outbound traffic by default, allowing loopback and an optional address such as your jump host
  • Snapshots the firewall configuration before changing it; Restore puts that snapshot back
  • Exact restore on Windows and Linux; best-effort on macOS
  • GUI + console
  • Reversible
  • Requires admin rights
✓ Included with Nadirion Desktop
TRI-03

Triage Kit USB

Builds an incident-response collection kit on a USB drive, with collectors that need nothing installed on the host.

  • Standalone Windows and Linux/macOS collectors that need nothing installed, plus a portable console of the command-line modules for hosts with Python 3
  • Collectors write their results to the kit, not to the host
  • A SHA-256 manifest of collected files, and a Verify Kit check that re-hashes them to show whether anything changed
  • GUI + console
  • SHA-256 manifest
✓ Included with Nadirion Desktop
TRI-04

USB ISO Burner

Writes a live-boot ISO or an OS installer to a USB drive, checking the image before writing and reading the drive back afterward.

  • Raw (DD) mode for hybrid ISOs; file-copy mode for Windows installers, with Secure Boot support
  • Checks the image against a checksum you supply before writing, and reads the drive back afterward
  • Offers only removable drives, re-identified at write time
  • GUI + console
  • Requires admin rights
✓ Included with Nadirion Desktop

Cryptography

Offline decoding, layer peeling, and hash-type suggestions for encoded and obfuscated text.

1 module
CRY-01

Decoder

An offline workbench for encoded, obfuscated, and hashed text.

  • 21 codecs, from Base64 and Base85 to Morse, ROT47, and gzip
  • Auto-peel strips nested layers and reports each one it removed
  • Ranks likely hash algorithms and tries dictionary recovery, including salted schemes
  • GUI
  • Fully offline

Quantum

Inventory the RSA and elliptic-curve cryptography that a large quantum computer is expected to break, and plan a move to post-quantum algorithms.

1 module
QNT-01

Cryptographic Inventory

Flags RSA and elliptic-curve cryptography in code, keys, certificates, and configuration, then drafts a phased plan for moving to post-quantum algorithms.

  • Scans code, keys and certificates, TLS/SSH/VPN configuration, dependencies, and (opt-in) live endpoints
  • Scores harvest-now, decrypt-later exposure against published timelines such as NIST IR 8547 and CNSA 2.0
  • A four-wave migration plan with HTML, CSV, CycloneDX CBOM, and SARIF exports
  • GUI + console
  • CI-ready

Where free tools cover similar ground

Many of these jobs can be done with free, well-regarded tools, and for some work they are the better choice. What Nadirion adds is one interface and command console for all of it, scores that list the rules behind them, offline operation, and host changes that ask first and can be undone.
