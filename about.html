→ About Nadirion

Named for a point of reference.

The nadir is the point directly beneath an observer, opposite the zenith: a fixed point of reference. Nadirion makes Nadirion Desktop, which brings analyst tools into one launcher and one command console on Windows, macOS, and Linux.

See Nadirion Desktop Contact Us

01 What We Make

One desktop app for analyst tools.

Nadirion Desktop runs 33 modules for host triage, artifact and log review, email and indicator analysis, a post-quantum cryptography inventory, and network and host utilities. Twelve come with every license; the rest are add-ons, so each analyst pays only for the modules their work needs.

It is built around a few rules: show the reasoning behind each score, ask before changing a host, and keep changes reversible where the platform allows. Two more modules are in development; nothing is sold until it ships.
